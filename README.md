# KIKX Android Runner

The Android/WebView runner for [KIKX](https://github.com/luvbyte/kikx), built with
Sketchware Pro.

The [KIKX](https://github.com/luvbyte/kikx) server and
[KIKX MUI](https://github.com/luvbyte/kikx-mui) are maintained separately.

## Project

`Sketchware-pro/` contains the full Sketchware Pro project.
Its the extract packaged as .swb
